# lro-testbed

Static browser projects hosted from the repository root with GitHub Pages.

## Structure

- `index.html` is the central project index. Its styles live in `css/`.
- Each project has a folder at the root with its own `index.html`, `css/`, and `js/` folders. For example, `todo/` contains the TODO app.
- Add a link to each new project in the root index.

## Local development

Serve the repository root with any static web server and open `index.html`. The TODO app uses browser local storage to save tasks.
